# TaxiCheck

Сайт сравнения цен: такси, приложения (Uber, Bolt, FREE NOW), трансферы, премиум. Старт: Мюнхен и аэропорт MUC. Языки: RU, DE, EN.

## Где что лежит
- `src/lib/data.js` — тарифы, маршруты, цены, ссылки, источники с датами.
- `src/lib/texts.js` — все тексты на трёх языках.
- `src/lib/render.js` — расчёт цены и сборка блоков страницы.
- `src/pages/[lang]/` — главная, Impressum, Datenschutz (черновики, проверить у юриста).

## Как обновляется
Правки делает ИИ-помощник. После изменения в ветке `main` сайт сам собирается и публикуется (GitHub Pages, `.github/workflows/deploy.yml`).

Все цены и юридические тексты перед публикацией нужно проверить.
